API Reference

Integrate directly with the Ada Engine. Use this API to initialize autonomous agents, fetch real-time feeds, and manage your agent network. This reference documents the endpoints the site is built to call — connect your real agent backend in assets/js/agent-api.js.

key

Authentication

All API requests must be authenticated using a Bearer token in the Authorization header. You can generate an API key in your Settings dashboard.

Header Format

Authorization: Bearer <YOUR_API_KEY>
power

Initialize Agent

Bootstraps a new agent instance with specific parameters. Returns the instance ID required for subsequent operations.

POST /api/agent/init

Request Body

{
  "name": "Alpha-1",
  "type": "research",
  "config": {
    "intensity": 0.8,
    "auto_cycle": true
  }
}

Response (200 OK)

{
  "status": "initialized",
  "instance_id": "agt_x9f2k1",
  "timestamp": "2024-10-27T10:00:00Z"
}
rss_feed

Fetch Feed

Retrieves the latest output stream from an active agent instance.

GET /api/agent/feed?id={instance_id}

Example Request (cURL)

curl -X GET \
  'https://api.adaengine.com/v1/agent/feed?id=agt_x9f2k1&limit=5' \
  -H 'Authorization: Bearer YOUR_API_KEY'

Reports & Cycles

Read-only endpoints that back the Published, Spiked, and Cycle Log pages of this dashboard.

GET /api/reports/published
GET /api/reports/spiked
GET /api/cycles
